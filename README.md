# FinVoice – Talk to AI for Smarter Investment

FinVoice is a multilingual stock analysis application that combines machine learning and voice interaction to help users analyze stock trends and obtain investment-related insights.

🚀 Features

- 📈 Stock trend analysis
- 🤖 LSTM-based stock price forecasting
- 🎤 Voice-based interaction
- 🌐 Multilingual support for Indian languages
- 🔊 Text-to-speech responses
- 📊 Interactive stock comparison and visualization
- 💡 Investment insights and recommendations

 🛠️ Technologies Used

- Python
- Streamlit
- Machine Learning
- LSTM
- Speech Recognition
- Google Translate
- Matplotlib
- NumPy
- Pandas

 🔄 How It Works

```text
User Input
    ↓

    ↓

💻 Installation

Clone the repository:

git clone https://github.com/GOPATHI-RISHITHA/FinVoiceApp.git

Navigate to the project directory:

cd FinVoiceApp

Install the required dependencies:

pip install -r requirements.txt

Run the Streamlit application:

streamlit run FinVoice.py
